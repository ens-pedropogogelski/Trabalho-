Adicionar uma seção de serviços ou destaques:
Crie uma nova seção abaixo do conteúdo principal da página.
Adicione três elementos que representem serviços, produtos, notícias ou destaques relacionados ao tema escolhido.
Cada elemento deve conter um ícone ou imagem, um título e uma descrição.
Organize os três elementos lado a lado em telas grandes.
Em telas menores, reorganize os elementos para que continuem legíveis e bem distribuídos.
Adicionar uma seção de chamada para ação:
Abaixo da nova seção, crie uma área de destaque para convidar o visitante a realizar alguma ação relacionada ao site.
Exemplos: conhecer os produtos, realizar uma inscrição, entrar em contato ou saber mais sobre determinado assunto.
A seção deverá conter:
Um título.
Um texto explicativo.
Um botão ou link.
Estilização CSS própria.
Ajustes de tamanho, espaçamento e alinhamento para telas menores.
